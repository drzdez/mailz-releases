# mailz releases

Installers of **mailz**, a local, read-only mirror of your mailboxes with search, a folder view and a command line
for scripts and AI agents.

Download the latest version from [Releases](https://github.com/drzdez/mailz-releases/releases/latest):

| System | File |
|---|---|
| Windows | `mailz_<version>_x64_en-US.msi` |
| Fedora and other RPM-based Linux | `mailz-<version>-1.x86_64.rpm` |
| Debian, Ubuntu | `mailz_<version>_amd64.deb` |
| Other Linux | `mailz_<version>_x86_64.flatpak` |
| Linux without a desktop | `mailz-cli_<version>_linux_x86_64.tar.gz` (command line only) |

Installed mailz checks this page for updates (Help > Check for updates); the installers are signed for the updater.
This repository holds releases only.
